# おみくじアプリ
人生初のWebアプリです。Webアプリ作成の練習として作成しました。

## 概要
ボタンを押すとランダムでおみくじ結果が表示されます。

## こだわりポイント
- ボタンにカーソルを合わせると、ボタン上の文字が青くなり、カーソルが変化します。
- 結果とともに画像も出てくるので、視覚的にも楽しめます！
- 出る結果によって出る確率が違います。大吉が出るまでぜひチャレンジしてください！

## 苦戦したポイント
- ボタン上の文字が青くなる設定にしたとき、一度カーソルを合わせるとずっと青くなってしまっていたので、離したら青くなるように変更しました。大きな苦戦ではないですが、初めて見つけた課題だったので、自分の中では苦戦しました。
- 結果の画像を自分で作るのに苦戦しました。結果に合った画像にする必要があるので、デザインを工夫しました。また、一番良くない結果でも悲しい気分にならないように、明るい色を取り入れました。
- 最初に結果とともに画像を表示する設定にしたとき、ボタンを押すとボタンの位置が画像の分下にずれてしまい、とても操作しにくい状況でした。そこで、ボタンの位置と画像の位置を変更し、ボタンが常に同じ位置に来るように変更しました。
